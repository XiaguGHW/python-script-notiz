# HiWi – ISW Technische Assistenz der Professur im Bereich Künstliche Intelligenz

## 1. 岗位基本信息 / Stelleninformationen

**Institut:** Institut für Steuerungstechnik der Werkzeugmaschinen und Fertigungseinrichtungen (ISW), Universität Stuttgart  
**Bereich:** Künstliche Intelligenz / Softwareentwicklung / industrielle Automatisierung  
**Position:** Studentische Hilfskraft (m/w/d) – Technische Assistenz der Professur im Bereich Künstliche Intelligenz  
**Ansprechpartner:** Univ.-Prof. Dr. rer. nat. Andreas Wortmann  
**Status:** Die konkrete Ausschreibung ist auf der ISW-Webseite weiterhin als PDF verfügbar. Auf der aktuellen ISW-HiWi-Seite werden inzwischen andere aktuelle HiWi-Stellen aufgelistet; diese konkrete KI-Assistenzstelle wird dort nicht mehr separat genannt. Daher ist es sinnvoll, vor bzw. mit der Bewerbung kurz zu fragen, ob die Stelle noch verfügbar ist oder ob es aktuell eine ähnliche Tätigkeit im Bereich KI / Softwareentwicklung gibt.

## 3. Hintergrund / 背景

### Deutsch

Das ISW forscht an der Schnittstelle von Automatisierung, Produktionstechnik und Softwareentwicklung. In der ausgeschriebenen HiWi-Stelle geht es darum, neue Erkenntnisse aus der künstlichen Intelligenz zu analysieren und prototypisch auf ihren möglichen Nutzen für das ISW zu untersuchen. Der Schwerpunkt liegt damit klar auf KI-naher Softwareentwicklung und der praktischen Evaluierung neuer Methoden.

### 中文

ISW 的研究位于自动化、生产技术和软件开发的交叉领域。这个 HiWi 岗位主要希望分析最新的人工智能方法，并通过软件原型评估这些方法在 ISW 研究中的实际价值。因此岗位重点非常明确地偏向 AI 相关的软件开发和新方法验证。

## 4. Aufgaben / 工作内容

### Deutsch

Laut Ausschreibung gehören folgende Aufgaben dazu:

- Analyse von KI-Methoden
- Objektorientierte Software-Entwicklung in Python
- Entwicklung von Software-Prototypen im Frontend und Backend
- Einrichtung von CI/CD-Infrastrukturen zur Evaluierung der entwickelten Prototypen

### 中文

根据岗位说明，主要工作包括：

- 分析和评估人工智能方法
- 使用 Python 进行面向对象的软件开发
- 开发 Frontend / Backend 软件原型
- 搭建 CI/CD 基础设施，用于测试和评估开发出的软件原型

## 5. Anforderungen / 岗位要求

### Deutsch

- Studium der Informatik oder Softwaretechnik
- Erfahrung in der Programmierung
- Erfahrung im Umgang mit Programmierwerkzeugen wie IDE und Git

### 中文

- 官网原岗位写的是 Informatik 或 Softwaretechnik 专业学生
- 有编程经验
- 熟悉 IDE、Git 等开发工具

### Hinweis / 注意

这里最大的潜在问题是：岗位原文明确写了 **„Studium der Informatik oder Softwaretechnik“**。你目前是 Fahrzeugtechnik Master，不是它列出的专业。

不过你的实际经历和岗位任务本身是高度匹配的：

- Python
- Machine Learning / LLM
- Datenaufbereitung
- Modellvergleich und Evaluation
- ROS2 / Robotik
- Git / softwarebezogene Projektarbeit

因此申请时不需要回避专业不同，而应该用 1–2 句具体项目经验证明你具备实际能力。

## 7. Online-/Homeoffice-Eignung / 线上适配度

**Einschätzung: sehr hoch – ca. 5/5**

这个岗位的大部分任务都是纯电脑端工作：

- Python 开发
- AI 方法分析
- Frontend / Backend 原型
- Git / IDE
- CI/CD

因此从任务性质看，它非常适合部分甚至大部分远程完成。

不过需要注意：**岗位公告本身没有明确写 Homeoffice / Remote möglich**，因此这只是根据任务内容判断，不能视为官方承诺。

相比实验室、测量、机器人硬件、试验台类 HiWi，这个岗位明显更适合线上工作。

## 9. Empfohlene Bewerbungsstrategie / 建议申请思路

因为这份 PDF 仍在线，但当前 ISW 学生岗位页面已经主要列出其他新的 HiWi，所以邮件最好不要假定这个具体岗位一定还开放。

建议邮件逻辑：

1. 说明你看到了他之前发布的 KI-Technische-Assistenz HiWi；
2. 简短说明你虽然是 Fahrzeugtechnik Master，但当前 Masterarbeit 正在做 LLM / Machine Learning / Datenaufbereitung；
3. 再补一句以前有 ROS2 / autonome Navigation 的软件项目经验；
4. 询问该岗位是否仍开放，或者目前是否有类似 AI / Softwareentwicklung HiWi；
5. 附 Lebenslauf。

不要写得太长，也不用专门解释“为什么不是 Informatik”。让具体技术经历自己证明匹配度即可。
