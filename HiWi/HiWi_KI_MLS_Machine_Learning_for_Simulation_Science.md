## 3. Forschungsschwerpunkte / 研究方向

### Deutsch

Die Abteilung Machine Learning for Simulation Science beschäftigt sich mit modernen Machine-Learning-Methoden für wissenschaftliche und simulationsbasierte Anwendungen. Dazu gehören unter anderem:

- Machine Learning für physikalische Systeme
- Machine Learning für Moleküle
- Machine Learning für biomedizinische Anwendungen
- Generative Modelle wie Diffusion Models
- Vision-Language Models und Large Language Models
- Graph-basierte Lernverfahren
- Few-Shot Learning und Foundation Models
- Datengetriebene Modellierung komplexer Systeme

### 中文

Machine Learning for Simulation Science 主要研究将现代机器学习方法用于科学计算和仿真问题，包括：

- 面向物理系统的机器学习
- 分子方向机器学习
- 生物医学方向机器学习
- Diffusion Models 等生成式模型
- Vision-Language Models（VLM）和 Large Language Models（LLM）
- 图结构机器学习
- Few-Shot Learning 与 Foundation Models
- 复杂系统的数据驱动建模

## 6. Warum dieser Bereich interessant ist / 为什么值得主动联系

MLS 的研究方向和纯数据/机器学习工作高度重合，很多任务本身主要在电脑上完成，例如模型训练、数据分析、仿真结果处理、论文调研和代码实现。

当前公开的 Student Theses 中也能看到非常接近 AI/ML 的题目，例如：

- Deep Learning Based Identification of Recurring Load Paths from Topology Optimized Structures in Rail Vehicles
- Hierarchical Guidance for Diffusion Models via Tree-Structured Data Clustering
- Graph-Based Few-Shot Adaptation of Multiple Vision-Language Foundation Models in the Pathology Domain

因此，即使当前没有公开 HiWi vacancy，主动询问也有实际意义。

3. 强调 Python、Datenaufbereitung、Machine Learning 和数据类项目经验；
4. 可以顺带提到你对 generative AI / LLM / multimodale Modelle 等也有兴趣；

不需要假装申请某个已经公开的具体岗位。
